# מערכת חילוץ טפסי התחייבות רפואיים

מערכת Full-Stack עם ממשק React ושירות FastAPI לחילוץ פרטים מטופסי התחייבות רפואיים. המערכת מעבדת כל עמוד בנפרד, מציגה שדות לבדיקה, ומאפשרת תיקון, אישור ושמירה ב-SQLite או ב-Supabase.

## רכיבים

- [backend/](./backend/) — API, OCR מקומי באמצעות Tesseract, כללי חילוץ, אחסון, יומן אירועים וייצוא Excel.
- [frontend/](./frontend/) — ממשק RTL להעלאה, מעקב עיבוד, בדיקת השדות, תיקון ואישור.

## מסלול עיבוד בקצרה

1. הקובץ מתקבל ב-API; בהעלאה מרובה הוא נשמר זמנית בתור מקומי.
2. PDF ותמונות נבדקים ומרונדרים לעמודי PNG.
3. Tesseract מזהה טקסט בעברית ובאנגלית; הטקסט משמש לזיהוי סוג הטופס ולחילוץ מבוסס תוויות.
4. ערכי השדות מנורמלים ונבדקים, וכל ערך חסר/לא ודאי מסומן לבדיקה.
5. כל מספר מרכזי נשמר כרשימה; כל מספר התחייבות נשמר בנפרד כמזהה של שורת ייצוא.
6. התוצאות נשמרות ב-SQLite או ב-Supabase. תמונות התצוגה נשמרות בזיכרון בלבד והקובץ הזמני נמחק בתום עבודת האצווה.

## מנועי חילוץ ופרטיות

ברירת המחדל היא `EXTRACTION_MODE=local_ocr_rules`: OCR וכללי חילוץ מקומיים בלבד. ניתן להגדיר במפורש `EXTRACTION_MODE=gemini` או `EXTRACTION_MODE=hybrid`; מצבים אלה שולחים תמונות עמודים ל-Gemini. אין לבחור בהם עבור מידע רפואי ללא אישור מתאים. אין בקוד מסלול Ollama פעיל.

קובץ `.env.example` מכיל את הגדרות המנוע, Tesseract, ואת פרטי Supabase לדוגמה. מפתח Supabase מסוג `service_role` נשמר ב-backend בלבד. יש להוסיף אימות והרשאות מתאימות לפני שימוש בנתונים רפואיים אמיתיים.

## יומן אירועים

אירועי שלבי העיבוד ופעולות המשתמש (תיקון, בדיקה, אישור, מחיקה וייצוא) נכתבים מקומית לקובץ `backend/data/logs/extraction-events.jsonl`, עם סיבוב קבצים מוגבל. אפשר לקרוא אותם דרך `GET /api/logs?batch_id=<id>&trace_id=<id>&document_id=<id>&limit=200`. היומן מתעד פונקציות, שלבים, זמני ריצה, ספקים, שדות שנמצאו/חסרים ותוצאות אימות; הוא אינו שומר טקסט OCR או ערכי שדות.

## הפעלה ובדיקות

יש להתקין את חבילות Python מתוך `backend/requirements.txt`, את Tesseract עם `heb` ו-`eng`, ואת חבילות frontend מתוך `frontend/package.json`.

```powershell
cd backend
uvicorn app.main:app --reload --port 8001
```

```powershell
cd frontend
npm run dev
```

בדיקות backend:

```powershell
cd backend
python -m unittest discover -s tests
```
