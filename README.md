# מערכת חילוץ טפסי התחייבות רפואיים

מערכת Full-Stack עם ממשק React ושירות FastAPI לחילוץ נתונים מטפסים רפואיים, עם עיבוד מקומי ותמיכה בטקסט עברי ובכתב־יד באמצעות מודל ראייה־שפה מקומי.

## רכיבי הפרויקט

- [backend/](./backend/) — API, צינור PDF/תמונה, OCR וחילוץ מקומיים, SQLite לפיתוח או Supabase לשמירה קבועה, חיפוש וייצוא Excel.
- [frontend/](./frontend/) — ממשק RTL להעלאה, התקדמות הצינור, צפייה במסמך עם סימון אזורי החילוץ, בדיקה ותיקון של התוצאות.

## הפעלה

יש לעקוב אחר הוראות ההתקנה ב־[backend/README.md](./backend/README.md), להתקין Ollama עם מודל vision מתאים, ולהתקין Tesseract עם שפות `heb` ו־`eng` עבור OCR משווה.

ה־backend אינו שולח מסמכים לשירות AI חיצוני. קובצי המקור אינם מועלים ל־Supabase; התוצאות הרפואיות נשמרות ב־SQLite או ב־Supabase לפי התצורה. יש לקרוא את מגבלות הפרטיות והאבטחה לפני שימוש בנתונים אמיתיים.
